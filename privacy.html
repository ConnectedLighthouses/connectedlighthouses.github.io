Privacy Policy

Executively Functional · Last updated 9 November 2026

Executively Functional is a personal planning app with one user: the person who built it. It is not offered to the public. This page explains what it does with Google account data.

What it reads

  • Google Calendar, read-only: events in the days around today, to show what is already planned.
  • Google Tasks, read-only: open tasks, to show alongside the day.

It cannot create, change or delete events or tasks.

How the data is used

Calendar and task data is read when the app is opened, and used only to show the user their own day and suggest how to use the open time. It is not sold, shared with anyone, used for advertising, or sent to any AI service.

What is stored, and where

  • The sign-in token that lets the app read the calendar and tasks. It is kept on the user's own computer or private server, not on a third-party service.
  • A log of the app's own suggestions and which ones the user ticked off, kept in the same place, so the user can see what helped.

Calendar events and tasks themselves are not saved.

Removing access

The user can disconnect Calendar or Tasks inside the app, which deletes the stored token. Access can also be removed at any time from Google account permissions.

Google API Services

Executively Functional's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
